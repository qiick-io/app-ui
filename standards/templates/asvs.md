# OWASP ASVS 5.0 Level 2 assessment

Use the [OWASP ASVS 5.0.0 requirement source](https://asvs.owasp.org/downloads/) to assess the product. Level 2 includes both levels 1 and 2. Record the assessed version and scope, including optional features and any operator-managed controls.

Use **Met**, **Partial**, **Not applicable** or **Gap** in each row. Cite a test name, file or setting in **Evidence** and state the reason for any exception, missing verification or non-applicability. Link an `[asvs]` issue for every gap. Use the reporting path in `SECURITY.md` for sensitive details.

If a qiick package provides the control, put its Composer name in **Owner package** and cite a versioned F12 checklist row or test and the evidence that the product uses that control. Leave the owner cell blank for product-owned controls.
