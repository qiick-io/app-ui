# UI section for a qiick app's AGENTS.md / CLAUDE.md

Superseded by the [standards pack](../standards/README.md): set `uiPreset` in the app's `qiick-standards.json` and run the sync. It writes these UI rules, with the app's preset, into `AGENTS.md`, `CLAUDE.md`, `.github/copilot-instructions.md` and `.cursor/rules/accessibility-and-theme.mdc`, and the drift check keeps them current. Do not copy a UI section by hand.
